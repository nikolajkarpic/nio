# Personas

### P-1 Effort owner

Who: a developer who starts an effort and drives coding agents through it. (source: dev, 2026-11-15)
Wants: specs, plans and code that agents build without guessing, with every decision readable later, at a cost that fits their subscriptions. (source: dev, 2026-11-15)
Allowed to: answer grills, approve gates, rule on capped jury batches, park or abandon the effort, and merge it. (source: dev, 2026-11-15)
How often: daily, several efforts a week. (source: dev, 2026-11-15)

### P-2 Teammate

Who: another developer on the same repo who pulls it and works on their own efforts. (source: dev, 2026-11-15)
Wants: to read why past decisions were made and to review an effort someone else started. (source: dev, 2026-11-15)
Allowed to: read memory and specs, comment, and rule on a capped jury batch of someone else's effort when asked; never approve its gates or merge it. (source: dev, 2026-11-15)
How often: weekly, when pulled in to review or rule. (source: dev, 2026-11-15)

### P-3 Maintainer

Who: whoever installs NIO in a repo and owns its shared config. (source: dev, 2026-11-15)
Wants: NIO set up once for the whole team, with hosts, models, budgets and permission prompts chosen for everyone. (source: dev, 2026-11-15)
Allowed to: install NIO, change the committed team config, and choose whether stage commands run without permission prompts for the repo. (source: dev, 2026-11-15)
How often: rarely, at install and when the config changes. (source: dev, 2026-11-15)
