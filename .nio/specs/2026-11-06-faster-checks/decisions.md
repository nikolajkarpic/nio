| Decision | Options considered | Chosen | Why | Consequence |
| --- | --- | --- | --- | --- |
| Fold #75 into this effort (coordinator, during the grill) | fold in; leave for later | fold in | the spec wasn't past its gate; same code as #71 | #75 joins the PR's Closes line |
| How much of #75 (grill Q6) | through #71's reuse; also re-run only what the fix diff touched; leave out | through #71's reuse (FR-13) | a fix task closing an epic runs the suite at the fix commit (RF-10), so reuse removes the round's big cost with no new mechanism | lint, type checks, misuse tests and non-test journeys still re-run in a fix-check round (none are used in this repo) |
| Parallel files at once (grill Q1, D-261106-qo2r) | 8 fixed; core count; unbounded | 8 fixed | the issue's example; leaves cores for the tests' own git and Python subprocesses | on a smaller machine 8 may oversubscribe; change one number in `.nio/config.json` |
| Failure behaviour of the parallel suite (grill Q2) | run all, non-zero if any failed; stop at first; first file's code | run all, non-zero if any failed | every failing file shows in one run; `xargs` does it for free | a failing run takes as long as a passing one |
| Inline field slips (grill Q3, D-261106-opl2) | template shows gap/where + case-insensitive labels; default missing fields; parse several pairs per bullet | template + case-insensitive labels | the rejected outputs omitted the fields because the template has no line for them (RF-6) | a finding still missing gap/where stays invalid and is re-emitted |
| `None.` under Findings (FR-9, grill Q9) | exactly one line, none in any case plus one . or !; any trailing punctuation; any line starting with none | one line plus one . or ! | the human asked for it in #74; a looser form would swallow "None, but see F1" (spec jury J-4, J-19) | none, NONE!, None. mean no findings; None. followed by findings is invalid |
| When evidence reuses the review's suite run (grill Q4, D-261106-grjt) | same commit + configured suite + exit 0; any result with output stored; never | same commit + configured suite + exit 0 | a passing run needs no parsing, so the review line only carries command and exit code | a failing or `tests.epic` run still re-runs the suite in the copy |
| Which journey counts as covered (grill Q5) | suite's own per-file command with nothing added, suite passed; any command naming a test file; a config list | the suite's own per-file command | never skips a run that differs (e.g. `NIO_E2E=1`) | a journey with an extra flag still runs |
| Build order (plan) | issue order #73, #72, #71, #74; coordinator's #74, #71, #75, #73, #72 | coordinator's order | the parser and evidence changes don't depend on the test helpers; the parallel suite is measured last, on the faster files | the timing numbers come at the end of the effort |
| Load the embedding model once per process (plan, CT-2) | cache the model; cache each query's vector; leave it | cache the model | with the CLI in-process its 145 loads were the largest remaining cost of test_implement.py (RF-11); a model is read-only | one long-lived process keeps the model in memory |
| Keep every file running when one is killed (plan, CT-3) | `sh -c '… \|\| exit 1'` per file; plain `xargs -n1` | wrap each file | plain `xargs` stops starting files after a signal kill or exit 255 (RF-12) | one `sh` per file, negligible |
| How a covered journey is recorded (plan, CT-5) | `passed` plus `covered: true`; a new result `covered` | `passed` plus `covered: true` | every reader of results.json keeps its meaning of `result` | the pack shows the journey as passed, with the marker |
| Where "clean tree" is checked (plan, CT-5) | the last commit is the flow's own `T-n` commit; a separate dirty flag in history | the `T-n` commit | that commit stages every path the tests see (RF-8), so no new field is needed | a hand-made commit after the task disables reuse |
| How NFR-1 is measured (plan) | QS-1 by hand; a timing test in the suite | QS-1 | a file can't time itself, and a timing test would fail under load | the number is reported in the PR, not enforced |
| Keep the epic-close and evidence suite serial until T-6 (implement) | override `tests.suite` locally to the parallel command now; keep serial | keep serial | a trial parallel run before the in-process helper failed `test_nfr3_status_speed` (a 2 s bound on a CLI subprocess under load); T-5 removes that startup cost first | E-1 and E-2 pay the serial suite (about 9 min) at review and evidence |
